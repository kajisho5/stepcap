## Show HN (English)

**Title**

Show HN: stepcap – record a task once, get a guide for people and a SKILL.md for agents

**Text**

stepcap records what you do on your desktop (clicks, typing, app switches) in any app,
browsers included, and turns one recording into two things: a step-by-step guide for
people (guide.md, a single-file guide.html, a printable checklist) and an Agent Skill
(SKILL.md + annotated screenshots) that Claude Code, Codex or another agent can follow.
It runs on your computer only: no account, no cloud, works offline. Windows, macOS and
Linux (X11). It is for people whose free browser-extension recorder cannot capture
desktop apps, and for anyone who wants their agent to repeat a task they showed it once.
Optional: voice notes transcribed locally, and an MCP server so agents can read
recordings. The demo images are synthetic (demos/build.py). The release binaries are not
code-signed yet, so Windows and macOS will warn on first start.
MIT licensed: https://github.com/kajisho5/stepcap
